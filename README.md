# AI_NO_Programming_Pony
基于瑞萨RA4M2的零编程嵌入式学习套件
软件定位

AI导师是“智能小马”AI辅助嵌入式学习套件的 Windows 上位机软件，面向青少年、嵌入式初学者以及开展科普教学的教师。它把瑞萨 RA4M2 工程、源码阅读与编辑、AI对话、分步课程、编译输出和固件烧录放在同一个界面中，让学习者从一个可观察的小任务出发，逐步理解代码如何影响真实硬件。

智能小马套件包含 RA4M2 主控、四足与尾部共五路舵机、OLED 显示屏和蓝牙模块。软件可配合 LED、OLED、舵机及整机示例工程使用。学习者可以先提出“改变 LED 闪烁速度”“切换屏幕表情”“让尾巴多摇几次”等需求，再查看源码变化、编译日志和小马的实际反应。

## 主要功能

**结合当前工程答疑。** 软件打开瑞萨 RA 工程后，向 AI 导师提供当前工程结构、源码和接口信息。导师能够围绕实际文件与函数解释问题，减少仅凭通用示例回答带来的偏差。工程中的 README 和课程内容也可为接线、参数及教学步骤提供背景。

**按学习阶段提供两种模式。** 初级模式允许 AI 在当前工程的 `src/` 目录内受控修改源文件，并展示修改前后的真实差异；修改前会保存快照，学习者可撤销本轮改动。高级模式提供十七课进阶路径，覆盖工程创建、时钟与引脚配置、PWM、UART、I²C、动作控制、OLED、编译烧录及蓝牙联调。此时 AI 主要读取工程、解释原理和诊断问题，不直接替学生修改源码。

**连接真实开发流程。** 软件提供工程文件树、代码编辑器、构建输出与问题定位，并可从模板创建 LED、舵机、OLED 和完整机器马工程。对于已经配置好构建环境的工程，界面可调用工具链编译，检查本次固件产物，再通过 Renesas Flash Programmer 命令行工具烧录。编译错误会显示在输出面板，方便回到对应文件和行号排查。

**让修改可检查、可恢复。** 初级模式限制 AI 的编辑范围，不允许其直接改动 `ra/`、`ra_gen/`、`ra_cfg/` 等由配置工具生成的内容。涉及引脚、时钟或新增外设的任务，应在 RA Smart Configurator 中完成配置。软件呈现磁盘上实际发生的文件差异，便于学习者在烧录前确认改动。

## 典型使用流程

1. 打开已有的 e² studio 工程，或从软件内置模板创建新工程。
2. 选择初级或高级模式，围绕当前工程提出问题或按课程完成任务。
3. 检查 AI 建议与源码改动，必要时自行编辑并保存文件。
4. 使用软件的“一键编译”生成本次固件，阅读构建输出并处理错误。
5. 连接开发板，确认串口和 BOOT 状态后烧录固件。
6. 观察 LED、OLED 或机器马动作是否符合预期；若不符合，再检查代码、配置、接线和供电。

AI导师将自然语言交互用于降低入门门槛，同时保留真实源码、开发工具和硬件验证过程。编译成功只说明程序通过构建，最终效果仍需在实机上确认。

## 适用场景与运行条件

软件适用于中学科技社团、科普课堂、夏令营和高校嵌入式入门实践。Windows 打包版可直接从 `AITEACHER/dist/RenesasHorseTutor/RenesasHorseTutor.exe` 启动，但应保留其所在的完整文件夹。AI 对话依赖可用的网络模型接口；工程编译还需要相应的 Arm GNU 工具链与 GNU Make，烧录需要开发板连接和正确的串口设置。软件不替代硬件接线、外设配置及实机测试。

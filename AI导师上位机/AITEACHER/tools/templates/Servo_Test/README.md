# 舵机控制工程 — 给 AI 助手看的说明

用 GPT 定时器输出 PWM 驱动舵机。开机后无限循环地摇尾巴。

这份说明写的是**从源码里读不出来**的事实。函数清单直接读 `src/PWM.h`、`src/action.h`。

---

## 硬件外设

只有 **GPT ch4**（尾巴那一路 PWM，`Tail_ctrl`）。**没有 I2C、没有串口** ——
学生要屏幕或蓝牙，得先去 RASC 加，改 C 代码没用。

`PWM.h` 里声明了 `Front_Init` / `R_Rear_Init` / `L_Rear_Init` 这些，
但**这个工程只配了尾巴一路**，其它几路没有对应的 FSP 配置，别去调。

---

## 占空比是什么意思

PWM 周期 **20 ms（50 Hz）**，`Tail_SetDuty(n)` 里的 `n` 是百分比：

| duty | 脉宽 | 位置 |
|---|---|---|
| 3 | 0.6 ms | 一端 |
| **7** | **1.4 ms** | **中位** |
| 11 | 2.2 ms | 另一端 |

> ⚠️ **安全范围大约是 2.5 ~ 12.5。** 超出去舵机会一直往死顶、堵转发烫，
> 时间长了会烧。`SetDuty` 内部只挡了 `> 100`，**它不会帮你拦住 20 或 50**。

---

## 改哪里

`action.c` 里的 `Shake_Tail()`：

```c
for (int i = 0; i < 5; i++) {          // ← 摇几下
    Tail_SetDuty(3);
    R_BSP_SoftwareDelay(250, ...);     // ← 摇多快（越小越快）
    Tail_SetDuty(11);
    R_BSP_SoftwareDelay(250, ...);
}
```

"摇快一点"改延时，"多摇几下"改循环次数，"幅度小一点"把 3/11 往 7 靠。
`hal_entry.c` 里是 `while(1) { Shake_Tail(); }`，所以它一直在摇。

延时是阻塞的（`R_BSP_SoftwareDelay`），这个工程里没有别的事要做，无所谓。

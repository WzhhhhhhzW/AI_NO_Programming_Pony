# 打包（PyInstaller）

```
uv pip install pyinstaller
pyinstaller RenesasHorseTutor.spec --noconfirm
```

产物是 `dist/RenesasHorseTutor/` 一整个文件夹，双击里面的
`RenesasHorseTutor.exe` 运行。**整个文件夹一起拷给别人**，不能只拷 exe。

## 必须在 Windows 上打包

PyInstaller 不做交叉编译，而且 `claude-agent-sdk` 的 wheel 是分平台的
（自带的 CLI 是原生二进制）。在 Arch 上打出来的包在 Windows 上跑不了。

在演示机（或任意一台 Windows）上：

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt pyinstaller
pyinstaller RenesasHorseTutor.spec --noconfirm
```

## 为什么是 onedir 不是 onefile

`claude-agent-sdk` 自带一个 **298MB** 的 `claude` CLI，加上 QtWebEngine，
成品 **≈950MB**。onefile 每次启动都要把这一坨解压到临时目录，开一次要等
十几秒，而且临时目录路径每次都变（旧代码里那句"打包 exe 的临时解压目录
每次启动会变"就是这么来的）。onedir 双击秒开。

## 三个会踩的坑（spec 里已经处理）

1. **`claude_agent_sdk/_bundled/claude.exe` 不会被自动收进去** —— 它是包
   里的二进制不是 .py。spec 显式把它放进 `binaries`，落到
   `_internal/claude_agent_sdk/_bundled/`；`advisor.bundled_cli_path()`
   再显式算出这个路径传给 SDK 的 `cli_path`，不依赖它自己的 `__file__` 推算。
2. **QtWebEngine** 要带 `QtWebEngineProcess.exe`、`.pak` 资源、ICU 数据。
   PyQt6 官方 hook 会处理，spec 里再 `collect_all` 兜一次底。
3. **数据文件在 `_internal/` 里，不在 exe 旁边**（PyInstaller 6.x 的改动）。
   `flasher.app_dir()` 因此优先用 `sys._MEIPASS`；`resource_dirs()` 会同时
   看 exe 旁边，方便事后往那儿丢 `tools/toolchain`。

## 打完之后自己验一遍

日志在 `%APPDATA%\RenesasHorseAI\logs\run_*.log`，启动后应当有这三行：

```
用打包进来的 claude CLI：...\_internal\claude_agent_sdk\_bundled\claude.exe
对话区页面加载完成，补发 N 条排队调用          ← QtWebEngine 正常
会话就绪                                      ← agent 起来了
```

少哪一行就是对应的哪一块没打进去。

## 体积能不能小点

能，但没必要（体积不是约束）。真要减：`_bundled/claude` 占 298MB，可以不打包
它、改成让演示机 `npm i -g @anthropic-ai/claude-code`，SDK 会自动去 PATH 里找。
不推荐——多一个现场依赖，不划算。

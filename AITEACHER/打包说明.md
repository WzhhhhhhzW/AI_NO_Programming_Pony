## 必须在 Windows 上打包

PyInstaller 不做交叉编译，而且 `claude-agent-sdk` 的 wheel 是分平台的
（自带的 CLI 是原生二进制）。在 Arch 上打出来的包在 Windows 上跑不了。

在演示机（或任意一台 Windows）上：

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt pyinstaller
pyinstaller RenesasHorseTutor.spec --noconfirm
```

## 为什么是 onedir 不是 onefile

`claude-agent-sdk` 自带一个 **298MB** 的 `claude` CLI，加上 QtWebEngine，
成品 **≈950MB**。onefile 每次启动都要把这一坨解压到临时目录，开一次要等
十几秒，而且临时目录路径每次都变（旧代码里那句"打包 exe 的临时解压目录
每次启动会变"就是这么来的）。onedir 双击秒开。

## 三个会踩的坑（spec 里已经处理）

1. **`claude_agent_sdk/_bundled/claude.exe` 不会被自动收进去** —— 它是包
   里的二进制不是 .py。spec 显式把它放进 `binaries`，落到
   `_internal/claude_agent_sdk/_bundled/`；`advisor.bundled_cli_path()`
   再显式算出这个路径传给 SDK 的 `cli_path`，不依赖它自己的 `__file__` 推算。
2. **QtWebEngine** 要带 `QtWebEngineProcess.exe`、`.pak` 资源、ICU 数据。
   PyQt6 官方 hook 会处理，spec 里再 `collect_all` 兜一次底。
3. **数据文件在 `_internal/` 里，不在 exe 旁边**（PyInstaller 6.x 的改动）。
   `flasher.app_dir()` 因此优先用 `sys._MEIPASS`；`resource_dirs()` 会同时
   看 exe 旁边，方便事后往那儿丢 `tools/toolchain`。

## 打完之后自己验一遍

spec 会限定本次构建的 DLL 搜索路径，并在打包后自动运行
`tools/verify_qt_bundle.py`，直接加载发行目录里的 QtCore、QtWidgets、
QtWebEngine 和 QScintilla。任何一个加载失败，打包命令都会报错退出。
也可以单独检查：

```
.venv\Scripts\python.exe tools\verify_qt_bundle.py dist\RenesasHorseTutor
```

如果修改了 DLL 搜索路径，要用新的 `--workpath` 重建，避免复用旧的依赖分析。
开发工具的 PATH 可能包含与 Windows 系统 DLL 同名的文件；例如 PDF 工具的
`icuuc.dll` 与 Qt 所需的 Windows ICU 接口不同，误收进发行包后会导致
`QtCore: 找不到指定的程序`。不要手动从其它软件目录补 DLL。

日志在 `%APPDATA%\RenesasHorseAI\logs\run_*.log`。启动后应有“启动”和
“对话区页面加载完成”。初级模式连接工程后，另有 CLI 和会话日志：

```
用打包进来的 claude CLI：...\_internal\claude_agent_sdk\_bundled\claude.exe
对话区页面加载完成，补发 N 条排队调用          ← QtWebEngine 正常
会话就绪                                      ← agent 起来了
```

V15.2 的高级模式直接使用 API 设置中的地址、密钥和模型，不启动工程 agent，
因此高级模式下不要求出现 CLI 和“会话就绪”日志。

## V16.16 尾巴跟踪修复（包含 V16.15 全部更新）

当前 DOG 工程 Tail_SetDuty(3/11) 对应 0.6/2.2ms，按零位 1.4ms 与 90°/ms 得到 -72/+72°。旧版统一 180°/s 让尾巴 350ms 内最多走 63°，无法完成两端切换。新增独立尾巴速度参数默认 600°/s、尾巴位置增益 32；保留四肢 180°/s、有限力矩和尾巴保持。

默认值是针对当前教学动作的仿真校准，并非实测舵机型号参数；物理环境可独立调整。check_tail_tracking.cjs 验证 30/60/120 FPS 下 350ms 端点误差小于 2°。

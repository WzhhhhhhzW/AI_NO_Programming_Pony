# Renesas 机器马 AI 导师 V16.19 版本更新说明

## 本次更新

- 顶部“进阶教程”入口更名为“教程资料”，方便集中查找软件、硬件与 API 学习资料。
- 新增《智能小马硬件安装教程》，共 25 页，包含材料说明、安装步骤和组装完成检查。
- 新增《蓝牙小马—AI 辅助零编程高级模式教程》，共 72 页。
- 新增《AI 时代第一课：API 的调用》，共 5 页，帮助初学者理解并配置 API。
- 三份教程随安装包离线提供，可在软件内直接阅读，支持目录、搜索、翻页和缩放。
- 放大图片取模、教程阅读器、串口调试等窗口中的按钮与数值上下调节区域，补充深浅主题下清晰可见的上下箭头，修复高分屏下点击不易生效的问题，并增加按下状态反馈。

## 安装方法

1. 下载 `RenesasHorseTutor_Setup_V16.19.exe`。
2. 双击安装程序并按照向导完成安装。
3. 启动“Renesas 机器马 AI 导师”，点击顶部“教程资料”查看新增内容。

适用于 Windows 10/11。

# 发行版本管理

- 用户要求：每次修改并生成新版后，删除上一版本，不保留多个可混淆的发行目录。
- 正式发行目录固定为 `dist/RenesasHorseTutor/`，只保留最新版本。
- 先完成新版构建和验证，再替换正式发行目录；清理旧的 `dist_*` 目录、旧构建产物和失败包备份。临时打包目录在发布后清理。
- 清理前确认目标绝对路径在本项目内，且没有运行中的程序依赖它；不要强制终止可能有未保存内容的用户程序。
- 不要删除源码、用户工程、`.venv` 或 `build/python`。本项目虚拟环境依赖 `build/python` 中的 Python 3.11 运行时。
